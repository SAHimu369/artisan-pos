# Artisan POS 🍔

> A clean, modern, and fully-featured Point of Sale (POS) web application built for cafes and small retail businesses.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 📖 About The Project

Artisan POS is a lightweight, client-side POS system that runs entirely in the browser. It uses `localStorage` for data persistence, meaning no backend is required for basic operation. It features inventory management, customer loyalty, and detailed sales reporting.

### ✨ Key Features

- **💰 Sales & Checkout**: Fast product search and a clean cart interface.
- **📦 Inventory Management**: Full CRUD for products with stock levels.
- **🍔 Product Variations**: Support for size options (Small, Medium, Large) with different prices.
- **👥 Customer & Loyalty**: Manage profiles and a points-based loyalty program.
- **📊 Reporting**: View sales trends, payment breakdowns, and top-selling products.
- **⚙️ Settings**: Customize currency, VAT rate, and branding.
- **✨ Smart Features**: Automatic round-up for cash totals and a 3D splash screen.

## 🛠️ Built With

- HTML5, CSS3, Vanilla JavaScript
- [Chart.js](https://www.chartjs.org/) for data visualization
- [Three.js](https://threejs.org/) for the 3D splash screen
- [Font Awesome](https://fontawesome.com/) for icons

## 🚀 Getting Started

To run this project locally, simply open the `index.html` file in your web browser.
